# Team guide

Current shared guide: [Perfume Core — team guide and data dictionary](https://docs.google.com/document/d/1BGJYUTEhlxZGnqxzpvb_WeTG8EtZ82a_YxB4gqlzrzo).

The Google Doc includes the relationship table from Auth to Customer/Staff, Catalog, Orders and Payments, plus the step-by-step migration and type-generation guide. Sharing permissions are managed in Google Drive.

`perfume-core-team-guide.docx` is the initial two-page import source. It predates the later Google Docs edits and is not a synchronized copy of the current guide.

The canonical installed schema reference remains [data-dictionary.md](../data-dictionary.md). Follow the migration-history warning in [the migrations README](../../../supabase/migrations/README.md) before any CLI push.
